# 📘 Portal SENAI — Aplicação Web

## 📖 Descrição
Este repositório contém os códigos‑fonte utilizados no desenvolvimento da aplicação web do Portal SENAI, criada como projeto da disciplina de Linguagem de Marcação. A aplicação foi desenvolvida com foco em simular a navegação e funcionalidades de um sistema institucional, utilizando HTML, CSS e JavaScript.

O sistema apresenta páginas interativas como:

1. Home institucional

2. Eventos SENAI

3. Categorias de cursos

4. Cursos inscritos com resumo de pagamento

Todas as telas foram construídas com atenção à estrutura semântica, responsividade e organização visual, respeitando os padrões de marca da instituição.

## 🛠️ Tecnologias Utilizadas
HTML5 — estrutura semântica das páginas

CSS3 — estilização visual e responsividade

JavaScript — interações básicas e simulação de funcionalidades
